# Job Tracker extension

The side panel: a Manifest V3 Chrome extension built with
[WXT](https://wxt.dev). It reads the Posting in the active tab, offers a Draft
to review, and saves it as a Job Application through the web app's API.

Setup, the dev server, how the default API base URL is chosen, and how to
connect the panel with a Personal Access Token are all in the
[repository README](../../README.md).
